## 🚀 Prochaines étapes (par ordre)

### Étape 1: Lancer localement (5 min)
```bash
git clone https://github.com/stanprat/tinalytvk.git
cd tinalytvk
npm install
npm run dev
# Ouvrir http://localhost:3000
```

### Étape 2: Personnaliser vos données (15 min)
1. Modifier `data/artworks.js` - Ajouter vos 6 œuvres d'exemple
2. Modifier `data/config.js` - Ajouter vos infos (nom, email, téléphone)
3. Uploader images dans `public/artworks/`

### Étape 3: Déployer en ligne (10 min)
1. Créer compte Vercel (gratuit): https://vercel.com
2. Connecter GitHub
3. Cliquer "Deploy"
4. Attendre 2 minutes
5. ✅ Votre site est en ligne!

### Étape 4: Ajouter plus d'œuvres
- Utiliser le guide [GESTION_OEUVRES.md](./GESTION_OEUVRES.md)
- Ajouter progressivement vos œuvres

### Étape 5: Optionnel - Améliorer
- Ajouter domaine personnalisé
- Intégrer paiement en ligne
- Google Analytics
- Réseaux sociaux intégrés

## 📞 Support

### Si vous avez une question:
1. Consulter [DEMARRAGE.md](./DEMARRAGE.md) - FAQ section
2. Lire la documentation pertinente (GESTION_OEUVRES.md, etc.)
3. Créer une issue sur GitHub
4. Contacter: stanprat@github.com

### Problèmes courants:

**"Les images n'apparaissent pas"**
→ Vérifier le chemin dans `image:` vs nom réel du fichier

**"Le site refuse de démarrer"**
→ Vérifier Node.js version: `node --version` (18+ requis)

**"Une œuvre n'apparaît pas"**
→ Vérifier la syntaxe JSON (virgules, accolades)
→ Valider sur https://jsonlint.com/

**"Vercel redéploie mais les changements n'apparaissent pas"**
→ Vider le cache du navigateur (Ctrl+Shift+Suppr)
→ Attendre 2-3 minutes (redéploiement en cours)

## 🎨 Personnalisation rapide

### Changer la couleur principale (or → autre):
- Ouvrir `tailwind.config.js`
- Modifier: `gold: '#d4af37'` → votre couleur hex
- Exemple: `gold: '#ff6b6b'` (rouge)

### Changer le nom du site:
- `app/layout.js` - Titre et description
- `data/config.js` - Nom de l'artiste
- `components/Header.js` - Logo/titre

### Ajouter des réseaux sociaux:
- `data/config.js` - URLs des réseaux
- Les liens apparaissent automatiquement
